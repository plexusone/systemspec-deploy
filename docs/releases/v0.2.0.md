# v0.2.0

**Release Date:** 2026-10-23

SystemSpec Deploy v0.2.0 moves the project to its new name and Go module path, `github.com/plexusone/systemspec-deploy`. It is the deployment topology specification of the SystemSpec family: what runs where, its images, ports and connections, and the cloud resources it uses.

This is a **breaking change** release for Go SDK users, because import paths change. The document format, the CLI and the graphize provider are unchanged, so existing `system.json` files work as before.

## Highlights

- **Breaking**: the Go module path is now `github.com/plexusone/systemspec-deploy`
- **Same format**: existing system spec documents validate and render without changes
- **Same CLI**: the `system-spec` command and its subcommands are unchanged; only the install path moves

## Breaking Changes

### Go module path

**Before (v0.1.0):**

```go
import (
    "github.com/plexusone/system-spec/spec"
    "github.com/plexusone/system-spec/graph"
    "github.com/plexusone/system-spec/render"
)
```

**After (v0.2.0):**

```go
import (
    "github.com/plexusone/systemspec-deploy/spec"
    "github.com/plexusone/systemspec-deploy/graph"
    "github.com/plexusone/systemspec-deploy/render"
)
```

Package names, types and functions are the same. Only the module path changes.

### Graphize provider import

**Before (v0.1.0):**

```go
import _ "github.com/plexusone/system-spec/graphize"
```

**After (v0.2.0):**

```go
import _ "github.com/plexusone/systemspec-deploy/graphize"
```

The provider still registers under the name `system-spec` and produces the same node and edge IDs, so existing graphs stay valid.

### JSON Schema `$id`

The generated schema's `$id` is now:

```
https://github.com/plexusone/systemspec-deploy/schema/system
```

Tools that match the schema by `$id` need the new value. The schema's structure is unchanged.

## Installation

```bash
# CLI
go install github.com/plexusone/systemspec-deploy/cmd/system-spec@v0.2.0

# Go SDK
go get github.com/plexusone/systemspec-deploy@v0.2.0
```

See the [migration guide](../guides/migrating-from-system-spec.md) for step-by-step instructions.
